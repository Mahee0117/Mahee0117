### 🎫 SupportCrew AI
**Multi-agent customer support with a QA feedback loop**

A ticket is triaged, routed by deterministic Python to a specialist agent, then reviewed by a QA agent. Rejected answers go back with feedback for a bounded retry.

- 🔎 Triage → 💳 Billing / 🛠️ Technical / 👤 Account / 💬 General → 🧪 QA
- 📦 Pydantic-validated outputs (`TriageResult`, `QAResult`)
- 🔁 Bounded retry loop (max 2 retries)
- 🏠 Fully local: Ollama + Qwen2 7B, zero API cost
- 🗺️ Roadmap: tools + RAG → CrewAI Flow → FastAPI + PostgreSQL + React

### 📬 Message Notification Router
**HackerRank Orchestrate 24-hour Hackathon**

A multimodal AI routing engine that decides per user and per message whether to `notify`, `digest` or `mute`, reasoning over text, images and voice notes.

- 🖼️ Gemma4 Vision for posters/screenshots, Whisper for voice
- 🛡️ Rule-based scam/spam signals feed the LLM judgment
- 🧾 Evidence-backed: cites historical message IDs
- 💾 Crash-safe incremental writes with auto-resume
- ✅ 110/110 valid predictions, zero duplicates, strict JSON validation
